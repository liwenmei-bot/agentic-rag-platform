# Frontend

Vue 3 + Vite 搭建的对话界面，配合后端实现流式打字机效果、多会话管理、知识图谱可视化、Agent 模式。

> 项目整体介绍、Docker 一键部署方式见根目录的 [`README.md`](../README.md)。下面是本地开发模式（`npm run dev`）的说明。

## 视觉设计说明

主题是"深色书房"——深蓝灰背景 + 暖琥珀色强调色，模拟"台灯下查资料"的氛围；对话正文区用暖白纸色，呼应"知识库/档案"的项目定位。引用来源做成"档案脚注"样式（琥珀色下划线 + 等宽字体），是这版设计里刻意突出的一个细节。

## 第四阶段新增：Agent 模式

- 对话窗口顶部新增"知识库问答 / Agent 模式"切换按钮
- Agent 模式下，回答之前会看到"执行过程日志"——正在调用哪个工具、调用结果摘要，像一条施工记录一样展示
- 如果 Agent 调用了 `generate_report` 工具，回答下方会出现一个可点击下载的文件标签

## 第三阶段新增：知识图谱可视化

- 侧边栏新增"对话 / 知识图谱"切换标签
- `src/components/GraphView.vue`：用 ECharts 的力导向图（force graph）渲染知识图谱，节点可拖拽、可缩放
- 上传文档后，侧边栏会显示这份文档抽取出的关系数量（比如"+5 关系"）

## 新增功能（相较第一阶段）

- 类 ChatGPT 的对话界面，替代之前只能用 `/docs` 页面测试
- 流式打字机效果（SSE）
- 多会话管理：新建、切换、删除，历史记录持久化（后端用 SQLite 存储）
- 侧边栏直接拖拽/点击上传文档，不用再手动调 API

```

```

## 快速开始

**前提**：先把第二阶段的后端跑起来（后端也做了对应改造，加了流式接口和会话存储，见 `backend/README.md`）。

```bash
cd frontend
npm install
npm run dev
```

启动后访问 **http://localhost:5173**，就能看到对话界面。

> `vite.config.js` 里配置了开发代理，前端请求 `/api/*` 会自动转发到后端的 `http://127.0.0.1:8000`，所以不需要在前端代码里写死后端地址，也不会有跨域问题。

## 验收自查清单

- [ ] 打开页面能看到侧边栏 + 对话区的整体布局
- [ ] 点击"新对话"能创建新会话，侧边栏出现新记录
- [ ] 上传文档后，侧边栏能看到文件名
- [ ] 提问后，回答是逐字出现的打字机效果，不是一次性弹出
- [ ] 回答下方能看到引用来源标签
- [ ] 切换到之前的会话，历史消息能正确回显
- [ ] 刷新页面后，之前的会话记录还在（因为后端存了 SQLite）

## 已知限制（留给后续阶段）

- 没有用户登录/鉴权，目前是单用户使用
- 没有对话删除确认弹窗，点击删除按钮直接生效
- 移动端适配比较基础，后续可以再打磨
